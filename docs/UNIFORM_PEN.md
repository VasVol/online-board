# Перо с постоянной толщиной

По запросу от 24 октября 2026 года свободное перо отображается с одинаковой толщиной независимо от скорости мыши и давления стилуса. Выбранные 2/4/6 px означают толщину штриха в координатах доски; масштаб увеличивает её пропорционально. Скруглённые окончания и сглаживание траектории сохраняются. Это не автоматическое выпрямление рукописных букв.

## Причина и решение

В Excalidraw 0.18.1 `getFreeDrawSvgPath` передаёт perfect-freehand `size = strokeWidth * 4.25` и `thinning = 0.6`. При мыши давление синтезируется из скорости; при стилусе используется входное давление. Это давало толстые участки и заострения. Публичного переключателя `thinning` в компоненте нет.

`scripts/patch-excalidraw.mjs` меняет только эти два параметра в **обоих** опубликованных JS-бандлах: `size = strokeWidth`, `thinning = 0`. Настройки smoothing/streamline остаются исходными. Мы сохраняем стандартный freedraw и его ввод, hit testing, историю и синхронизацию. Это небольшое документированное исключение из правила использовать публичный API.

Скрипт выполняется при `npm ci`, перед dev/build и E2E. Он проверяет точную версию 0.18.1 и однозначность исходного фрагмента; при другой версии или структуре завершает работу с ошибкой, а не молча пропускает адаптацию. Повторный запуск безопасен. После изменения удаляется только генерируемый Vite-кеш в `node_modules/.vite`.

Результат действует сразу во время жеста, у других участников, после reload, в PNG и SVG. Старые свободные штрихи также становятся ровнее **без изменений в БД**: координаты и записанные давления сохранены. Маркер использует тот же рендерер с увеличенной выбранной толщиной и прозрачностью. Пунктир/точки по-прежнему преобразуются в непрерывную линию после жеста.

Файл `.excalidraw` содержит стандартные исходные объекты. В стороннем редакторе без этой адаптации они могут отображаться с исходной переменной толщиной; для одинакового вида вне приложения используйте PNG/SVG.

## Проверки при обновлении SDK

Браузерный тест `pen width stays constant...` рисует мышью с разной плотностью точек и эмулирует стилус с давлением 0.1/0.95/0.4. Проверяет пиксели Canvas на нескольких участках при зажатой кнопке, после отпускания и после reload. Для живого штриха учитываются interactive и static Canvas: проверка только static дала бы ложную ошибку.

`npm run test:e2e` проверяет dev-бандл, `npm run test:e2e:production` — отдельную настоящую production-сборку с временной БД. Оба входят в `npm run check` и pre-commit. Production-тест не подменяет рабочий `dist/`; диагностический `VITE_E2E` включён только во временной сборке.

При обновлении Excalidraw сначала проверьте, не появился ли публичный параметр постоянной толщины, и предпочитайте его. Иначе явно пересмотрите оба фрагмента и эти тесты. Не редактируйте `node_modules` вручную без воспроизводимого скрипта.
