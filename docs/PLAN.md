# План реализации

Дата исследования: 24 октября 2026.

1. Сравнить лицензии и API готовых движков. Выбрать поддерживаемый свободный движок.
2. Сделать отдельные слои: React/Excalidraw; привязка сцены к Yjs; HTTP API; WebSocket; SQLite.
3. Каталог досок, переименование, страницы, гостевой доступ по секретной ссылке. Каталог привязан к браузеру владельца без регистрации.
4. Рисование, стирание, Select/Hand, выбор прямой/окружности одним нажатием L/C, цвета/толщина/стили, текст, изображения, undo/redo, экспорт.
5. Совместная работа сразу: документы Yjs на уровне страниц, курсоры, восстановление соединения, локальный IndexedDB.
6. Тесты: права доступа, изоляция страниц, одновременные правки, восстановление после перезапуска, сценарии браузера и работа клавиатуры. Обязательный pre-commit и CI.
7. Инструкции запуска Debian/сервер, Docker/Caddy, резервирование, архитектурные ограничения и расширение.

Дальнейшие этапы после проверки в реальных уроках: геометрические построения и LaTeX, PDF-страницы, аккаунты и роли, история версий, мониторинг нагрузки, затем распределение комнат между серверами. Нельзя обещать отсутствие зависаний при произвольном числе объектов: измерять отдельно число архивных страниц, активных комнат и объектов на текущей странице.
