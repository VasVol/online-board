## Рабочий запуск на ноутбуке

Готовая сборка запущена как постоянный пользовательский systemd-сервис **`pole`**, порт **3001**, данные — `data/`. Он установлен на диск, но не включён в автозапуск: после перезагрузки запускается ярлыком «Поле — доска для математики» на верхней панели GNOME Flashback. Прежний временный `online-board` остановлен.

```bash
systemctl --user status pole
systemctl --user stop pole
# После изменения кода:
npm run build
systemctl --user restart pole
```

Ярлык: `~/.local/share/applications/online-board.desktop`, команда: `~/.local/bin/online-board`, значок: `~/.local/share/icons/hicolor/scalable/apps/pole.svg`, unit: `~/.config/systemd/user/pole.service`. Установщик хранится в `scripts/install-desktop.py` и вызывается `npm run install:desktop`. Перед изменением панели создаётся backup в `~/.local/state/online-board/`. Проверены холодный запуск через команду ярлыка, health endpoint и повторный запуск с сохранением PID сервера. Desktop-файл прошёл `desktop-file-validate`, unit — `systemd-analyze --user verify`. Панель содержит один `launcher-online-board` в `top-panel`. Перед разработкой остановите `pole`, чтобы освободить порт 3001.

Открывайте [локальную доску](http://127.0.0.1:3001/). Сохраните ключ владельца через кнопку в каталоге. Для другого устройства той же сети используйте сетевой IP ноутбука; cookie владельца у другого hostname/IP будет другим. Восстановите ключ владельца, если нужен тот же каталог. Для гостя копируйте ссылку из доски, открытой через доступный гостю адрес.

## Постоянные инструменты, общая сетка и сбор участников — 27 октября 2026

- Нажатие L/C выбирает постоянный custom-инструмент через публичный Excalidraw API. Проверяются повторные прямые, окружности во всех четырёх направлениях, смена на перо, повторное рисование и ввод L/C в текстовом поле.
- Сетка синхронизируется между разными страницами одной доски. Браузерная проверка читает реальные пиксели сетки, проверяет отключение, reload и offline/reconnect. Серверные проверки подтверждают запись до broadcast и отсутствие ложной рассылки при ошибке SQLite.
- «Собрать всех» проверяется в независимых браузерах на разных и одинаковых страницах, с разными размерами окна.
